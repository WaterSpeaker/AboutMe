人物设定

我是一个体验设计师，上学那会儿写过一点代码，大致懂得一点工程知识，但离实际研发还是差很远的。这是我第一次用 vibe coding 搭建一个正式上线的网站，这篇文章试图回答几个问题：

  • 完全不会写代码的人如何搭建个人站
  • 有哪些可以合理利用的工具
  • 关于审美和“人味”

用到的工具

  • Vibe coding agent：Cursor（Fable 5 底模）
  • 飞书：文档、多维表格和问卷（Lark CLI 大家应该都配好了吧）
  • ChatGPT：我是 GPT 重度用户，所以它有很多关于“我是谁”的 context ，和它交流了很多要放什么内容的想法，以及不确定某块实现有没有现成的轮子的时候也会问问它；
  • Figma：画了个 logo
  • 审美教育：https://styles.refero.design/
  • 地图：https://maplibre.org/
  • 之前写过的很多小作文：Working with Chen

构思

想做个人站的原因，是因为希望自己可以试着多 vibe coding 一些东西，个人站是一个很适合的，每个人都可以尝试的方式；

我有一些好玩的经历，想试着用可视化的方式表现出来；

希望通过这样的方式，去建立多一些人和人之间的链接。希望大家看完之后会觉得，哦这个人还是有点意思的。

页面结构如下：

  • 首页：个人介绍、我喜欢的书影音、我的一些经历和照片
  • 播客：几期精选内容、报名嘉宾的入口
  • 越野跑：近期比赛和训练目标
  • 旅行：去过的国家/城市
  • 博客：之前写的杂七杂八的内容

怎么写第一个页面

我的第一轮 prompt：

我有一个播客，想为它做一个网页，包括这几块内容：
1. 关于这个播客的一段文字介绍；
2. 几期 feature内容展示，包括标题、正文和播放链接；
3. “申请当嘉宾”的提报按钮，点击可打开一个表单；
此外，我可以为你提供我想参考的视觉风格和我这个播客的网页链接。
我要如何开始着手搭建这个网页，你建议的步骤是怎么样的

然后就让 Agent 给你说下步骤， 看着大致没问题就可以继续搞下去了。

第一个页面搭完之后，我花了一些时间去调整视觉，打磨差不多了再开始做其他页面。现在的 Agent 还是很聪明的，会在你给到的初步需求基础上补充很多“无用但有趣”的细节。

Tips: 可以使用 Plan 模式或者 Grill-me 这个 Skill，在启动前理清楚思路

怎么让页面变好看

首先，你要选一个有审美的底模。

其次，我用的工具是 https://styles.refero.design/，可以在这里挑选你喜欢的界面风格然后丢给 AI，让它学习这个风格。更多介绍可以看看这个文档：AI 不会做设计？先给它一份 DESIGN.md

prompt如下：

你是资深前端设计工程师，接下来请基于这个 Refero Styles 页面 [链接地址] 里的 DESIGN.md、CSS Variables、Tailwind v4 和 Design Tokens，调整当前页面的视觉风格和布局。

开始写代码前先做三件事：

读取 DESIGN.md 和 tokens；

输出 5 条不可违反的视觉原则；

给出页面结构草案。

实现时必须把 tokens 接入主题层，组件样式优先使用 tokens；请从当前 Refero 页面提取主 CTA 颜色、卡片处理方式、圆角、字号、间距和按钮高度等规则。

交付时请列出修改文件，并按颜色、字体、间距、圆角、卡片、CTA、图片使用逐项自查。

再然后遇到了很有趣的问题：目前市面上能看到的好的设计网站基本都是英文的，这就意味着如果你要搭一个中文网站，需要换字体，那么接下来，需要一点额外的中文排版审美教育。

这不只是字体的问题。把西文换成中文之后，还涉及到间距、字号等一系列微妙的细节。

我暂时没有找到足够满意的中文排版网站。所以最终是让 GPT 给了我一份字体建议，丢给 Agent 更新之后，在此基础上再进行了一些主观调整。这部分我也不知道要如何描述了，也许之后可以考虑写一个 skill（可能是所谓的 taste 的部分，以及作为一个设计师天然知道要怎么描述样式怎么调整）

以下是 GPT 给我的建议，但这份建议有效的前提是我想做一个很“我”的网站，所以我挑选的视觉风格，和 GPT 给到我的字体建议都是在此基础上的，不具有普适性。

怎么让你做的东西少点儿 AI 味

答案是：多花一点人类的时间。

我和不少朋友沟通过，普遍反馈都是：虽然大部分人没法很清楚地描述出“AI 味”是什么，但大家都能识别什么是 AI 写的。以及，当识别到这是 AI 写的东西之后，就不再有兴趣阅读它了。

如果你不愿意花人类的时间去创作，那么另一个人类又有什么理由花时间去阅读它呢。

大家都在用 AI 辅助创作，但，最终的作者还是人。这是人类对人类的尊重。

Next steps

我其实并不觉得现在这个网站是一个“完成品”，但我也意识到也许永远没有做完的一刻，永远在迭代更新的路上。但，至少目前是一个可以分享出来的 MVP 版本，因为收集别人的意见，也是更新灵感的重要来源。

之后会增加的部分可能有：

  • 怎么更有趣。增加一些动效、彩蛋的部分（ https://openprocessing.org/ https://transitions.dev/ ）
  • 更多 vibe coding demo。我也不知道之后还会做点啥，想到了再说；
  • 让更多人愿意和我互动。我觉得很多时候人和人之间缺乏一些开始聊天的契机，也许兴趣爱好、去过的地方看过的书做过的东西，会是一些链接的可能性。所以我设置了一些简短的问题，包括推荐有意思的旅游地点，申请成为播客嘉宾。但也许还能做一些别的。
